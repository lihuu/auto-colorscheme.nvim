NAME                                                           *mac-auto-theme*

    mac-auto-theme.nvim - Automatically follow macOS appearance (dark/light)
    and switch Neovim background + colorscheme.

INTRODUCTION                                           *mac-auto-theme-intro*

    A lightweight Neovim plugin for macOS that tracks the system appearance
    using the native `defaults` command and applies the configured dark or
    light colorscheme. On non-macOS systems the plugin disables itself and
    leaves your setup untouched.

REQUIREMENTS                                         *mac-auto-theme-require*

    - macOS with the `defaults` command available.
    - Neovim with LuaJIT (for uv timers).
    - Installed colorschemes for dark and light modes. Defaults assume
      `tokyonight` and `dayfox` are available.

INSTALLATION                                       *mac-auto-theme-install*

    Use your plugin manager of choice. Examples:

    lazy.nvim ~
        {
          "your-username/mac-auto-theme.nvim",
          lazy = false,
          priority = 1000,
          dependencies = {
            "folke/tokyonight.nvim",
            "EdenEast/nightfox.nvim",
          },
          config = function()
            require("mac-auto-theme").setup({
              mode = "auto",
              darkScheme = "tokyonight",
              lightScheme = "dayfox",
            })
          end,
        }

    packer.nvim ~
        use {
          "your-username/mac-auto-theme.nvim",
          requires = {
            "folke/tokyonight.nvim",
            "EdenEast/nightfox.nvim",
          },
          config = function()
            require("mac-auto-theme").setup({
              mode = "auto",
              darkScheme = "tokyonight",
              lightScheme = "dayfox",
            })
          end,
        }

    vim-plug ~
        Plug 'folke/tokyonight.nvim'
        Plug 'EdenEast/nightfox.nvim'
        Plug 'your-username/mac-auto-theme.nvim'

        lua << EOF
        require("mac-auto-theme").setup({
          mode = "auto",
          darkScheme = "tokyonight",
          lightScheme = "dayfox",
        })
        EOF

COMMANDS                                           *mac-auto-theme-commands*

    :MacTheme {mode}
        Control the plugin mode.
        {mode} can be one of: "auto", "light", "dark".

        - auto : follow macOS appearance and poll periodically.
        - light: force light mode and stop automatic polling.
        - dark : force dark mode and stop automatic polling.

CONFIGURATION                                   *mac-auto-theme-configuration*

    Call setup() in your config. Options are merged with defaults.

        require("mac-auto-theme").setup({
          mode = "auto",        -- "auto" | "light" | "dark"
          interval = 2000,       -- polling interval in milliseconds
          darkScheme = "tokyonight", -- colorscheme used in dark mode
          lightScheme = "dayfox",    -- colorscheme used in light mode
          notify = true,         -- show notifications when switching
        })

    Notes:
      - If you change the scheme names, ensure those themes are installed.
      - On non-macOS systems setup() returns early and does nothing.

BEHAVIOR                                               *mac-auto-theme-notes*

    - Uses a non-blocking uv timer to poll the system appearance.
    - Colorschemes are applied with pcall to avoid errors if a scheme is
      missing; background may still change.
    - The plugin keeps track of the last applied state to avoid redundant
      reapplication.
